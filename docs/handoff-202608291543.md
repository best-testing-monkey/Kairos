### Regenerating the papers

Both generators read their figures from JSON rather than transcribed constants, specifically
so they cannot drift from the data:

```
docs/papers/build_paper.py          <- paper_table.json        (The Prediction Premium)
docs/papers/build_market_report.py  <- market_analysis3.json   (Where Strategies Travel)
docs/papers/analyze_by_market3.py   regenerates market_analysis3.json from the DB
docs/papers/audit_paper.py          re-derives the paper's figures from the DB and
                                    cross-checks the published HTML (currently passes)
```

Run a generator **from `docs/papers/`** and it writes a standalone doctype'd file there; run
it **from a scratchpad** and it writes a head-less artifact-publish source there *and*
refreshes the repo copy. Publish the scratchpad copy, never the `docs/papers/` one — the
Artifact tool rejects the doctype.

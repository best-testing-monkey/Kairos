Full table with exact numbers was presented to Baz in the previous chat turn (not repeated here — re-derive if needed via the SQL query below, or ask the next session to re-run it):
```sql
SELECT ps.strategy_name, ps.ticker, ps.model_label,
  COUNT(*) as n_signals,
  SUM(CASE WHEN pc.resolved=1 THEN 1 ELSE 0 END) as n_resolved,
  ROUND(100.0 * SUM(CASE WHEN pc.resolved=1 AND pc.pct_profit > 0 THEN 1 ELSE 0 END) / NULLIF(SUM(CASE WHEN pc.resolved=1 THEN 1 ELSE 0 END),0), 1) as win_rate_pct,
  ROUND(AVG(CASE WHEN pc.resolved=1 THEN pc.pct_profit END), 3) as avg_pct_profit,
  ROUND(SUM(CASE WHEN pc.resolved=1 THEN pc.pct_profit END), 2) as sum_pct_profit
FROM papertrade_signals ps
JOIN papertrade_signals_closure pc ON ps.signal_id = pc.signal_id
WHERE ps.interval='1h' AND ps.as_of >= '2026-08-07' AND ps.as_of <= '2026-08-21'
GROUP BY ps.strategy_name, ps.ticker, ps.model_label
HAVING n_resolved > 0
ORDER BY sum_pct_profit ASC;
```
